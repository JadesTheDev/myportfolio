IT-0001 — Storage Replacement and Linux Workstation Deployment

Project: Lenovo IdeaCentre 510A-15ICB / Penguin-Master
Category: Endpoint Hardware / Operating Systems
Status: Resolved (original deployment)
Work period: November 16–19, 2026
Technician: Jade Powell

1. Service request

Replace an older Lenovo desktop's hard-disk-based storage with a solid-state drive and deploy a practical Linux development workstation.

2. Asset details

SystemLenovo IdeaCentre 510A-15ICB
BoardLenovo 36EB
StoragePNY CS900 500 GB SATA SSD
Operating systemLinux Mint 22.3
Hostnamepenguin-master

3. Work completed

  1. Identified model and compatible SATA replacement storage.
  2. Installed SSD using SATA data and power connections.
  3. Prepared bootable Linux Mint USB media with Rufus.
  4. Navigated firmware boot selection and UEFI/GRUB behavior.
  5. Installed Linux Mint 22.3 onto the replacement SSD.
  6. Removed installation media and confirmed an independent boot.
  7. Continued development-workstation configuration.

4. Validation and resolution

Resolved: Linux Mint booted successfully from the new internal SSD without the installer USB. The machine was subsequently used as penguin-master.

Follow-on password/login or configuration issues are outside this completed storage-and-installation ticket. No unmeasured performance gains are claimed.

5. Skills demonstrated

Hardware compatibility assessment, SATA connections, SSD replacement, boot-media creation, UEFI/GRUB troubleshooting, Linux installation, deployment verification, and service documentation.

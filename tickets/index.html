Lenovo SSD replacement & Linux Mint deployment

Service request

Modernize an older Lenovo workstation's storage and move it to a functioning Linux desktop environment.

Work log

  1. Identified the Lenovo model and compatible SATA hardware.
  2. Installed a PNY CS900 500 GB SSD with SATA power and data connections.
  3. Prepared Linux Mint installation media with Rufus.
  4. Worked through UEFI/GRUB boot selection and installed Linux Mint 22.3.
  5. Removed the installer USB and confirmed an independent SSD boot.
  6. Configured the continuing Linux workstation under the hostname penguin-master.

Validation

Linux Mint booted successfully from the internal replacement SSD without installation media. Later workstation login and configuration issues belong in separate follow-on work.
